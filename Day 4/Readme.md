# Day 4 – Java Programming Practice

## Overview
This directory contains Java programming exercises completed as part of my daily Java training. The focus of Day 4 was on understanding Java Collections and applying programming concepts through practical examples.

## Programs

### 1. ArrayListExample.java
- Introduction to the `ArrayList` collection.
- Adding, accessing, updating, and removing elements.
- Understanding dynamic data storage in Java.

### 2. LinkedListExample.java
- Introduction to the `LinkedList` collection.
- Performing basic collection operations.
- Understanding dynamic data management in Java.

### 3. FoodDelivery.java
- Implementation of a food delivery scenario using Java.
- Application of programming fundamentals to a real-world use case.
- Practice in structuring and organizing Java code.

## Technologies Used
- **Language:** Java
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## How to Run
1. Clone the repository or download the source files.
2. Navigate to the `Day 4` directory.
3. Compile the required Java program:

   ```bash
   javac ArrayListExample.java
   ```

4. Execute the compiled program:

   ```bash
   java ArrayListExample
   ```

Replace `ArrayListExample` with the appropriate class name for the program you want to run.
